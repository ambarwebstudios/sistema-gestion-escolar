# Sistema de Gestión Escolar 🏫

Aplicación web de práctica para administrar información académica mediante operaciones CRUD.

## Tecnologías
- PHP
- MySQL
- JavaScript
- HTML5 y CSS3

## Funcionalidades
Gestión de registros académicos desde un panel web y persistencia de datos en MySQL.

## Configuración
Requiere un servidor PHP con MySQL y una base de datos compatible con las consultas del proyecto.

Configurá las variables de entorno `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS` y `PANEL_PASS` en el servidor antes de abrir `index.php`.

**Seguridad:** no publiques contraseñas, datos personales reales ni archivos de configuración con credenciales. El esquema SQL y las instrucciones de instalación completa están pendientes de documentar.

## Estado
Proyecto de práctica. No es una aplicación de producción ni una demo pública lista para desplegar.
